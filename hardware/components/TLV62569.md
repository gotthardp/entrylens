# Pin requirements: TLV62569

- References:
  - Datasheet: `tlv62569.pdf`, "Pin Configuration and Functions" (Pin Functions table)
- Package / orderable variant this table applies to: SOT23-5 (DBV package), TLV62569DBVR - this
  package has no PG or NC pin (those exist only on the 6-pin SOT23-6/SOT563-6 variants)

## Per-pin requirements

| Pin (SOT23-5) | Function | Requirement |
|---|---|---|
| 1 (EN) | Enable, input | Logic high enables the device; logic low disables it (shutdown). Do not leave floating. |
| 2 (GND) | Ground, power | |
| 3 (SW) | Switch, power | Connected to the internal FET switches and inductor terminal - connect the output filter's inductor to this pin. |
| 4 (VIN) | Power supply input, power | |
| 5 (FB) | Feedback, input | Connect to an external feedback divider for the internal control loop. |

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| VIN, EN, PG voltage | -0.3 to 6 V | Absolute maximum |
| SW voltage (DC) | -0.3 to VIN + 0.3 V | Absolute maximum |
| SW voltage (AC, pulses < 10 ns) | -3.0 to 9 V | Absolute maximum |
| FB voltage | -0.3 to 5.5 V | Absolute maximum |
| VIN | 2.5 to 5.5 V | Recommended operating condition |
| VUVLO (undervoltage lockout) | 2.3 min / 2.45 max V | VIN falling, 100 mV hysteresis |
| VOUT | 0.6 to VIN V | Recommended operating condition |
| VFB (feedback regulation voltage) | 0.588 min / 0.6 typ / 0.612 max V | |
| IOUT | 0 to 2 A | Recommended operating condition |
| Operating junction temperature | -40 to 125 degC | Recommended operating condition |
| Thermal shutdown | 150 degC rising / 130 degC falling | |
| RDS(on), high-side FET | 100 mOhm typ | - |
| RDS(on), low-side FET | 60 mOhm typ | - |
| ILIM (high-side FET current limit) | 3 A min | TLV62569DBV / TLV62569PDDC package |
