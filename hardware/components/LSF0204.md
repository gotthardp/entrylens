- References:

  - LSF family application note: `slva675b.pdf` (section 1: theory of operation; 3: pull-up

  - Schematic checklist for TXB, TXS and LSF translators: `spradj3.pdf` (sections 2.2 to 2.6)
- Package / orderable variant this table applies to: TSSOP-14 (PW package), LSF0204PWR. The
  LSF0204D variant has an active-low EN and is not interchangeable.

## Per-pin requirements

| Pin (PW) | Function | Requirement |
|---|---|---|
| 1 (Vref_A) | Reference supply, A side | Must be the lowest voltage level. Also supplies the EN input circuit. If Vref_A comes from an LDO, the LDO must sink the bias current from Vref_B, (Vref_B - Vref_A - 0.8 V) / 200 kOhm, or a 100 kOhm pull-down on Vref_A is recommended (SPRADJ3 2.2.1). |
| 2-5 (A1-A4) | Data port A, I/O | Channel n pairs An with Bn. |
| 6, 9 (NC) | No connection | Not internally connected. |
| 7 (GND) | Ground | |
| 8 (EN) | Enable, active high | VIH 0.7 x Vref_A, VIL 0.3 x Vref_A; must stay within 0 to Vref_A. Low = all I/O Hi-Z; "EN must be LOW to ensure the high-impedance state during power-up or power-down." TI recommends always enabled for I2C (10.2.1.1.1); Figure 10-1 drives EN from a separate 1.8 V enable signal. SPRADJ3 2.2.3: keep the device disabled until both supplies are stable. EN input transition rate 10 ns/V is typical only (7.5). |
| 10-13 (B4-B1) | Data port B, I/O | **Reverse order**: B4 is pin 10, B1 is pin 13. |
| 14 (Vref_B) | Reference supply, B side | At least Vref_A + 0.8 V; 1.0 V above Vref_A recommended. The 200 kOhm bias resistor is internal (9.2; `slva675b.pdf` section 4), so Vref_B connects directly to the B-side supply. |

No power sequencing is required (section 11; SPRADJ3 2.2.3). With Vref_A = Vref_B = 0 V, all data
pins and EN are Hi-Z (9.3.5); "if either Vref_A or Vref_B are grounded, the switch behaves as an
open circuit" (`slva675b.pdf` 5.6).

Decoupling: the LSF0204 datasheet specifies none, and its layout example (Figure 12-1) shows none.
SPRADJ3 2.2.2 recommends 0.1 uF at every supply pin for TXB, TXS and LSF alike, because
"level-shifters can draw large transient currents"; in the LSF the signal current flows between A
and B, and the Vref pins carry only bias current (ICCA + ICCB, ICCBA below).

## Operation and pull-ups

Each channel is a pass FET with its gate at Vref_A + VTH. While either side is low, both sides are
one node through ron. Above about Vref_A - 0.5 V the FET turns off: up, a B-side pull-up raises B;
down, A is clamped at Vref_A - a **weak 1**, for which "TI recommends only high-impedance loads
because very small amounts of current will cause the output voltage to drop significantly"
(`slva675b.pdf` section 1).

Pull-up requirement by direction (`slva675b.pdf` section 5.2 and SPRADJ3 2.6; "Pullups are not
required on inputs driven by push-pull devices"):

| Direction | A side (lower voltage) | B side (higher voltage) |
|---|---|---|
| Up, A drives B | only if the A driver is open-drain, or with leakage > 1 uA | always required |
| Down, B drives A | not required when translating to Vref_A if receiver leakage is < 1 uA, unless signal integrity needs one | only if the B driver is open-drain |
| Bidirectional open-drain (I2C) | required | required |

Pull-downs: SPRADJ3 2.6, "Pull-downs are not recommended as they create a voltage divider network
with the pull-ups used." A pull-down also loads the weak 1 when the far side drives high.

Pull-up current limit (`slva675b.pdf` section 3): RPU = (VPU - 0.35 V) / 0.015 A for 15 mA through
the FET.
