# Pin requirements: MIC5504

- References:
  - Datasheet: `MIC5501-02-03-04-300mA-Single-Output-LDO-in-Small-Packages-DS20006006.pdf`,
    DS20006006C. Ratings and electrical characteristics in section 1.0 (bold values apply over
    TJ = -40 to 125 degC, the others at 25 degC only); pin table 3-1; capacitors, no-load
    stability and enable in section 4.0; SOT23-5 drawing C04-091-6BX in section 7.0.
  - LDO parameter definitions (general, not part-specific):
    `AN6030-LDO-Basics-Parameter-Definitions-Measurements-and-Calculations-DS00006030.pdf`
- Package / orderable variant this table applies to: SOT23-5 (M5), MIC5504-1.8YM5-TR (fixed
  1.8 V, auto-discharge, internal EN pull-down). The UDFN-4 (MT) variant has different pin
  numbers and an exposed pad.

## Per-pin requirements

| Pin (SOT23-5) | Function | Requirement |
|---|---|---|
| 1 (VIN) | Supply input | "An input capacitor of 1 uF is required from the input to ground to provide stability" (4.1); X5R or X7R. |
| 2 (GND) | Ground | |
| 3 (EN) | Enable, active high | High = on, low = off. Internal pull-down resistor, so the pin "may be left floating" (Table 3-1); the 4 MOhm value is typical only, so a floating EN is not guaranteed to stay below the 0.2 V logic-low limit. |
| 4 (NC) | No connection | Not internally connected. |
| 5 (VOUT) | Regulated output | "Require an output capacitor of 1 uF or greater to maintain stability"; performance is optimized for 1 uF and "does not improve significantly with larger capacitance" (4.2). Low-ESR X5R/X7R ceramic. When EN is low, an internal 25 Ohm load discharges the output capacitors. |

No soft-start is specified; the output rise is set by the turn-on time above. The part is stable
with no load (4.3). No thermal shutdown threshold is given.
