# Pin requirements: TPS25200

- References:
  - Datasheet: `tps25200.pdf`, Table 4-1 (Pin Functions)
- Package / orderable variant this table applies to: WSON-6 (DRV package), TPS25200DRVR

## Per-pin requirements

| Pin | Function | Requirement |
|---|---|---|
| 1 (OUT) | Protected power switch output, O | No specific termination stated beyond normal output routing. |
| 2 (ILIM) | Current-limit set, O | External resistor to GND sets the current-limit threshold. Recommended 33 kOhm <= RILIM <= 1100 kOhm. |
| 3 (FAULT) | Fault indicator, O | Active-low open-drain output, asserted during overcurrent, overvoltage, or overtemperature. Connect a pullup resistor to the logic I/O voltage. |
| 4 (EN) | Enable, I | Logic-level control input; driven high enables the power switch, low disables it. Cannot be left floating, and must be limited below the absolute maximum rating if tied to VIN. |
| 5 (GND) | Ground | Connect externally to PowerPAD. |
| 6 (IN) | Input voltage, I | Connect a 0.1 uF or greater ceramic capacitor from IN to GND as close to the IC as possible. |
| PAD (PowerPAD) | Thermal/ground pad | Internally connected to GND; used to heat-sink the part to the board. Connect PowerPAD to the GND terminal externally. |

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| Voltage on IN | -0.3 to 20 V | Absolute maximum |
| Voltage on OUT, EN, ILIM, FAULT | -0.3 to 7 V | Absolute maximum |
| Voltage from IN to OUT | -7 to 20 V | Absolute maximum |
| Continuous FAULT output sink current | 25 mA max | Absolute maximum |
| Continuous ILIM output source current | 150 uA max | Absolute maximum |
| VIN | 2.5 to 6.5 V | Recommended operating condition |
| VUVLO (input undervoltage lockout) | 2.35 / 2.45 V (min/max) | IN rising |
| V(OVLO) (input overvoltage lockout threshold) | 6.8 / 7.6 / 8.45 V (min/typ/max) | IN rising |
| VEN | 0 to 6.5 V | Recommended operating condition |
| EN terminal turn-on threshold | 1.9 V max | Input rising |
| EN terminal turn-off threshold | 0.6 V min | Input falling |
| EN leakage current | -2 to 2 uA | VEN = 0 V or 5.5 V |
| IFAULT (continuous FAULT sink current) | 0 to 10 mA | Recommended operating condition |
| IOUT (continuous output current) | 2.6 A max | Recommended operating condition |
| V(OVC) (output overvoltage clamp threshold) | 5.25 / 5.4 / 5.55 V (min/typ/max) | CL = 1 uF, RL = 100 Ohm, VIN = 6.5 V |
| Operating junction temperature | -40 to 125 degC | Recommended operating condition |
| Thermal shutdown, OTSD2 (general) | 155 degC | - |
| Thermal shutdown, OTSD1 (only while in current limit) | 135 degC | Hysteresis 20 degC |
| rDS(on) (IN-OUT resistance) | 60 / 70 mOhm (typ/max) | TJ = 25 degC, IOUT = 2.5 A, 2.5 V <= VIN <= 5 V |
| rDS(on) (IN-OUT resistance) | 60 / 90 mOhm (typ/max) | -40 to 85 degC, IOUT = 2.5 A |
| rDS(on) (IN-OUT resistance) | 60 / 99 mOhm (typ/max) | -40 to 125 degC, IOUT = 2.5 A |
| Current limit, RILIM = 33 kOhm | 2773 / 2952 / 3127 mA (min/typ/max) | |
| Current limit, RILIM = 40.2 kOhm | 2270 / 2423 / 2570 mA (min/typ/max) | |
| Current limit, RILIM = 56 kOhm | 1620 / 1740 / 1860 mA (min/typ/max) | |
| Current limit, RILIM = 80.6 kOhm | 1110 / 1206 / 1300 mA (min/typ/max) | |
| Current limit, RILIM = 150 kOhm | 590 / 647 / 710 mA (min/typ/max) | |
| Current limit, RILIM = 1100 kOhm | 40 / 83 / 130 mA (min/typ/max) | |

Datasheet note: electrical characteristics conditions are -40 to 125 degC and 2.5-6.5 V VIN,
VEN = VIN, typical values at 25 degC. The current-limit table only lists the six RILIM values
above; it does not give a row for every possible resistor value.
