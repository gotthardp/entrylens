# Pin requirements: RAK3172

- References:
  - Datasheet: RAK3172 module datasheet (no local PDF, available online
    https://docs.rakwireless.com/product-categories/wisduo/rak3172-module/datasheet/), pin
    definition table for the IPEX-antenna variant.
  - Electrical limits below are instead sourced from the underlying MCU's own local datasheet,
    `stm32wle5cc.pdf` (Table 23, Table 74)
  - STM32WLE5 reference manual (register-level detail, not a pin datasheet):
    `rm0461-stm32wlex-advanced-armbased-32bit-mcus-with-subghz-radio-solution-stmicroelectronics.pdf`.
  - Schematic design guide:
    https://learn.rakwireless.com/hc/en-us/articles/32403676739607-how-to-design-schematic-for-rak3172-lorawan-module
  - Clarification that BOOT0 is pulled down internally by the module (RAK staff, forum):
    https://forum.rakwireless.com/t/rak3172-does-not-work/8475
- Package / orderable variant this table applies to: RAK3172-SM with IPEX antenna connector,
  RAK3172-8-SM-I (32-pin SMD module)

## Per-pin requirements

| Pin | Name | Requirement |
|---|---|---|
| 1 | PA3/UART2_RX | Reserved - UART2/LPUART1 interface (AT commands and firmware update). |
| 2 | PA2/UART2_TX | Reserved - UART2/LPUART1 interface (AT commands and firmware update). |
| 3 | PA15/PIN_A4 | GPIO and ADC. |
| 4 | PB6/UART1_TX | UART1 interface. |
| 5 | PB7/UART1_RX | UART1 interface. |
| 6 | PA1 | GPIO only. |
| 7 | PA13/SWDIO | Reserved - SWD debug pin (SWDIO). |
| 8 | PA14/SWCLK | Reserved - SWD debug pin (SWCLK). |
| 9 | PA12/I2C_SCL | GPIO and I2C (SCL). |
| 10 | PA11/I2C_SDA | GPIO and I2C (SDA). |
| 11 | GND | Ground. |
| 12 | RF  | RF Port, not available on IPEX variant. |
| 13 | PA7 | SPI1 (MOSI). |
| 14 | PA6 | SPI1 (MISO). |
| 15 | PA5 | SPI1 (CLK). |
| 16 | PA4 | SPI1 (NSS). |
| 17 | GND | Ground. |
| 18 | GND | Ground. |
| 19 | PA8 | GPIO only. |
| 20 | PA9 | GPIO only. |
| 21 | BOOT0 | Boot0 mode enable pin, high active. Per a RAK staff forum clarification (see header above), BOOT0 is pulled down internally by the module - no external strap is required. |
| 22 | RST | MCU reset (NRST). |
| 23 | GND | Ground. |
| 24 | VDD | Voltage supply. |
| 25 | PA10/PIN_A3 | GPIO and ADC. |
| 26 | PB2/PIN_A2 | GPIO and ADC. |
| 27 | PB12 | 10 kOhm internally pulled up for the high-frequency variant, or pulled down for the low-frequency variant. |
| 28 | GND | Ground. |
| 29 | PA0 | GPIO only. |
| 30 | PB5 | GPIO only. |
| 31 | PB4/PIN_A1 | GPIO and ADC. |
| 32 | PB3/PIN_A0 | GPIO and ADC. |

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| VDD (main supply voltage) | -0.3 to 3.9 V | Absolute maximum |
| VDD (standard operating voltage) | 2.0 to 3.6 V | Recommended operating condition |
| Operating current, TX | 87 mA | 20 dBm, 868 MHz |
| Operating current, RX | 5.22 mA | |
| VOH (output high level) | >= VDD - 0.4 V | CMOS port, IIO = 8 mA, VDD >= 2.7 V |
| VOH (output high level) | >= 2.4 V | TTL port, IIO = 8 mA, VDD >= 2.7 V |
| VOH (output high level) | >= VDD - 1.3 V | IIO = 20 mA, VDD >= 2.7 V |
| VOH (output high level) | >= VDD - 0.45 V | IIO = 4 mA, VDD >= 1.8 V |
| VOL (output low level) | <= 0.4 V | CMOS port, IIO = 8 mA |
| VOL (output low level) | <= 1.3 V | IIO = 20 mA |
| VOL (output low level) | <= 0.4 V | IIO = 4 mA, VDD >= 1.8 V |
| Output current sunk by any I/O or control pin | 20 mA | Absolute maximum |
| Output current sourced by any I/O or control pin | 20 mA | Absolute maximum |
| Total output current sunk, sum of all I/Os and control pins | 100 mA | Absolute maximum, must be distributed over all I/Os |
| Total output current sourced, sum of all I/Os and control pins | 100 mA | Absolute maximum, must be distributed over all I/Os |
| Operating temperature range | -20 to 85 degC | |
