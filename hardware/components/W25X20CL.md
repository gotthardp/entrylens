# Pin requirements: W25X20CL

- References:
  - Datasheet: `w25x20cl_revf 20150806.pdf`, section 5 (Pin Description), plus
    `AN0000026 Reference Schematic for Winbond SPI NOR Flash V1.2 01062020.pdf` for the pull
    resistor recommendations noted below (marked per-row)
  - PCB layout guideline: `AN0000009 SpiFlash PCB Layout Guideline v2.1 06122020.pdf`
- Package / orderable variant this table applies to: SOIC-8 150-mil (package code SN),
  W25X20CLSNIG

## Per-pin requirements

| Pin | Function | Requirement |
|---|---|---|
| 1 (/CS) | Chip Select, I | Deselected (high impedance outputs) when high; selects the device when low. Must transition high-to-low after power-up before a new instruction is accepted, and must track the VCC supply level at power-up - a pullup resistor can be used to accomplish this if needed. Per AN0000026: recommended pullup 4.7-10-50 kOhm (typ 10 kOhm) - control signals should not float. |
| 2 (DO/IO1) | Data output / bidirectional I/O, I/O | Standard SPI: unidirectional data output. Dual SPI: bidirectional I/O. High impedance when /CS is high. |
| 3 (/WP) | Write Protect, I | Active low. Used with the Status Register's Block Protect (TB/BP1/BP0) and Status Register Protect (SRP) bits to hardware-protect part or all of the memory array. Per AN0000026: recommended pullup (10-20 kOhm typical) since a low level is an unexpected active (hardware-protect) state; not needed only if the part has Quad-Enable "Q" suffix (this part does not) or the controller actively drives the pin during idle. |
| 4 (GND) | Ground | |
| 5 (DI/IO0) | Data input / bidirectional I/O, I/O | Standard SPI: unidirectional data input, written on the rising edge of CLK. Dual SPI: bidirectional I/O. |
| 6 (CLK) | Serial Clock, I | Provides timing for serial input/output. Per AN0000026 (generic SPI-flash guidance): recommended pulldown 47-100-500 kOhm if used, though not mandatory in space-constrained layouts. |
| 7 (/HOLD) | Hold, I | Active low. While /CS is low, driving /HOLD low pauses the device (DO goes high-impedance, DI/CLK ignored); driving it high resumes operation. Per AN0000026: recommended pullup (10-20 kOhm typical) since a low level unexpectedly holds the clock; not needed only if the part has Quad-Enable "Q" suffix (this part does not) or the controller actively drives the pin during idle. |
| 8 (VCC) | Power supply | |

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| VCC | -0.6 to 4.6 V | Absolute maximum |
| VCC (recommended operating range) | 2.7 to 3.6 V | At read frequency FR = 104 MHz / fast-read fR = 50 MHz. During Read, VCC must not deviate more than +/-10% from the VCC used during the last program/erase operation. |
| VWI (write inhibit threshold voltage) | 1.0 to 2.0 V | Writes are automatically inhibited when VCC falls below this level |
| Standby current (ICC1) | 10 typ / 50 max uA | /CS = VCC |
| Power-down current (ICC2) | 1 typ / 5 max uA | /CS = VCC |
| Read Data / Dual Output current (ICC3), 104 MHz | 6/7 typ / 12/14 max mA (single/dual output) | /CS = VCC, C = 0.1 VCC / 0.9 VCC, DO = Open |
| Write Status Register current (ICC4) | 8 typ / 12 max mA | /CS = VCC |
| Page Program current (ICC5) | 10 typ / 15 max mA | /CS = VCC |
| Sector/Block Erase current (ICC6) | 10 typ / 15 max mA | /CS = VCC |
| Chip Erase current (ICC7) | 10 typ / 15 max mA | /CS = VCC |
| Voltage on any pin (VIO) | -0.6 to VCC + 0.4 V | Absolute maximum |
| Transient voltage on any pin | -2.0 to VCC + 2.0 V | Absolute maximum, <20 ns transient |
| Ambient operating temperature | -40 to 85 degC | Industrial grade |
