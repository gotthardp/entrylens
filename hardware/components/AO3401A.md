# Pin requirements: AO3401A

- References:
  - Datasheet: `AO3401A.pdf`, "Absolute Maximum Ratings" and "Electrical Characteristics" tables
- Package / orderable variant this table applies to: SOT-23, AO3401A (P-channel MOSFET)

## Per-pin requirements

3-terminal part (Gate/Drain/Source MOSFET) - beyond identifying the three terminals in the
package pinout diagram, the datasheet does not assign a distinct requirement per pin.

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| Drain-source voltage (VDS) | -30 V | Absolute maximum |
| Gate-source voltage (VGS) | +/- 12 V | Absolute maximum |
| Continuous drain current (ID) | -4 A | Absolute maximum, TA = 25 degC |
| Continuous drain current (ID) | -3.2 A | Absolute maximum, TA = 70 degC |
| Pulsed drain current (IDM) | -27 A | Absolute maximum |
| Power dissipation (PD) | 1.4 W | TA = 25 degC |
| Power dissipation (PD) | 0.9 W | TA = 70 degC |
| Junction temperature | -55 to 150 degC | Absolute maximum |
| Drain-source breakdown voltage (BVDSS) | -30 V min | ID = -250 uA, VGS = 0 V |
| Gate threshold voltage (VGS(th)) | -0.5 / -0.9 / -1.3 V (min/typ/max) | VDS = VGS, ID = -250 uA |
| Static drain-source on-resistance (RDS(ON)) | 47 / 60 mOhm (typ/max) | VGS = -4.5 V, ID = -3.5 A |
| Static drain-source on-resistance (RDS(ON)) | 60 / 85 mOhm (typ/max) | VGS = -2.5 V, ID = -2.5 A |
