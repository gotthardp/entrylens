# Pin requirements: KT-0603R

- References:
  - Datasheet: `KT-0603R.pdf` (Kento Electronics), "Absolute Maximum Ratings" and "Electrical
    Optical Characteristics" tables
- Package / orderable variant this table applies to: 0603 (1.6 x 0.8 x 0.6 mm), red, KT-0603R

## Per-pin requirements

2-terminal part (single-die red LED) - the datasheet does not assign a distinct requirement per
terminal.

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| Forward voltage (VF) | 1.8 to 2.4 V | At IF = 20 mA |
| DC forward current | 25 mA | Absolute maximum |
| Peak forward current | 60 mA | Absolute maximum, 1/10 duty cycle, 0.1 ms pulse width |
| Reverse voltage (VR) | 5 V | Absolute maximum |
| Power dissipation (Pd) | 40 mW | Absolute maximum |
| Operating temperature range | -40 to 85 degC | |
