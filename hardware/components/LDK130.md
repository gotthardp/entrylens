# Pin requirements: LDK130

- References:
  - Datasheet: `ldk130.pdf`, Table 4 (Pin description, DFN6 1.2x1.3), Table 5 (Electrical
    characteristics for LDK130 adjustable version), Figure 4 (Typical application circuit for
    adjustable version)
- Package / orderable variant this table applies to: DFN6 1.2x1.3, LDK130PU-R (adjustable
  version; output voltage set externally via an R1/R2 feedback divider from OUT to the ADJ
  pin - not the fixed-voltage version documented in earlier revisions of this file. The
  SOT23-5L/SOT323-5L packages lack this part's 6th N/C pin.)

## Per-pin requirements

| Pin (DFN6) | Function | Requirement |
|---|---|---|
| 1 (OUT) | Output voltage | |
| 2 (GND) | Common ground | |
| 3 (ADJ) | Feedback/adjust input | Connect to the midpoint of an external R1/R2 divider from OUT to GND: VOUT = VADJ x (1 + R1/R2), VADJ = 0.8 V typical. |
| 4 (EN) | Enable, logic input | Low = shutdown, high = active. |
| 5 (N/C) | Not connected | Datasheet recommends connecting this pin to GND even though it has no internal function. |
| 6 (IN) | Input voltage | |

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| VIN (DC input voltage) | -0.3 to 7 V | Absolute maximum |
| VIN (operating input voltage) | 1.9 to 5.5 V | Recommended operating condition |
| VOUT (DC output voltage) | -0.3 to VIN + 0.3 V | Absolute maximum |
| VEN (enable input voltage) | -0.3 to VIN + 0.3 V | Absolute maximum |
| VADJ (bypass/adjust pin voltage) | 2 V | Absolute maximum |
| VADJ accuracy | 784 / 800 / 816 mV (min/typ/max) | IOUT = 1 mA, TJ = 25 degC |
| VADJ accuracy | -3.0 to 3.0 % | IOUT = 1 mA, -40 to 125 degC |
| IADJ (adjust pin bias current) | 1 uA max | - |
| Operating junction temperature | -40 to 125 degC | Absolute maximum |
| Thermal resistance, junction-ambient (RthJA) | 237 degC/W | DFN6 1.2x1.3 package |
| Thermal shutdown | 160 degC typ, 20 degC hysteresis | - |
| Dropout voltage (VDROP) | 100 mV typ | IOUT = 100 mA, VOUT = 2.5 V |
| Dropout voltage (VDROP) | 200 typ / 400 max mV | IOUT = 300 mA, 40 to 125 degC |
| Output capacitor (COUT) range | 1 to 22 uF | - |
