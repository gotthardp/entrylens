# Pin requirements: P25Q40SH

- References:
  - Datasheet: `P25Q40SH_Datasheet_V1.9.pdf`, revision V1.9, pin table in section 3.2,
    status/configure registers in section 7
  - Suggested land pattern for the SOP8 150-mil outline, which the datasheet does not give:
    `AN0000009 SpiFlash PCB Layout Guideline v2.1 06122020.pdf`
- Package / orderable variant this table applies to: SOP8 150-mil, P25Q40SH-SSH-IT (tube
  packing; the tape-and-reel variant is P25Q40SH-SSH-IR)

## Per-pin requirements

| Pin | Function | Requirement |
|---|---|---|
| 1 (CS#) | Chip select, input | Active low. Must not float - a low level selects the device. A 10 kOhm pullup keeps the part deselected while the controller's I/O is still tri-stated during reset and boot. |
| 2 (SO / SIO1) | Serial data output, or bidirectional I/O | Standard SPI: data output. Dual/Quad: bidirectional SIO1. |
| 3 (WP# / SIO2) | Write protect, input; or bidirectional I/O | Active low, protects the Status Register in conjunction with the block-protect and SRP bits. **Available only when QE = 0, which is the factory default.** If QE is set to 1 the pin becomes data I/O SIO2 and the write-protect function is lost. A pullup keeps write protection deasserted; a low level is an unexpected hardware-protect state. |
| 4 (GND) | Ground | |
| 5 (SI / SIO0) | Serial data input, or bidirectional I/O | Standard SPI: data input. Dual/Quad: bidirectional SIO0. |
| 6 (SCLK) | Serial clock, input | Provides timing for serial input and output. |
| 7 (HOLD# / RESET# , SIO3) | Hold or Reset, input; or bidirectional I/O | Function selected by the non-volatile HOLD/RST bit in the Configure Register: **HOLD/RST = 0 (factory default) makes the pin /HOLD**; HOLD/RST = 1 makes it /RESET. Both are active low, and **both are available only when QE = 0**. If QE is set to 1 the pin becomes data I/O SIO3 and both functions are disabled. A pullup keeps whichever function is selected deasserted. |
| 8 (VCC) | Power supply | |

Notes from the datasheet worth carrying forward:

- Section 7: "The Quad Enable (QE) bit is a non-volatile Read/Write bit in the Status
  Register that allows Quad operation. When the QE bit is set to 0 (Default) the WP# pin
  and HOLD# pin are enable. When the QE pin is set to 1, the Quad IO2 and IO3 pins are
  enabled." QE is a writable bit with a **default of 0**, so WP# and HOLD# are available as
  received.
- Same section: "The QE bit should never be set to 1 during standard SPI or Dual SPI"
  operation when WP#/HOLD# are hard-tied - a pullup rather than a direct tie leaves this
  safe either way.
- The HOLD/RST bit offers a hardware /RESET input on pin 7 as an alternative to /HOLD. Using
  it would require the controller to drive that pin, which a 2-wire SPI connection does not.

## Electrical limits and consumption

| Parameter | Value | Conditions |
|---|---|---|
| VCC (operating) | 2.3 to 3.6 V | Read, erase and program |
| Ambient operating temperature | -40 to +85 degC | Device grade I |
| Deep power-down current (IDPD) | 0.2 typ / 2.5 max uA | CS# = VCC, all other inputs at 0 V or VCC |
| Read current (ICC1) | 2.0 typ / 2.5 max mA | f = 33 MHz (03h), IOUT = 0 mA |
| Read current (ICC1) | 8 typ / 14 max mA | f = 85 MHz, IOUT = 0 mA |
| Read current (ICC1) | 10 typ / 18 max mA | f = 104 MHz, IOUT = 0 mA |
| Program current (ICC2) | 2.5 typ / 4.0 max mA | CS# = VCC |
| Erase current (ICC3) | 2.5 typ / 4.0 max mA | CS# = VCC |
| Input low voltage (VIL) | -0.5 to 0.3 x VCC | |
| Input high voltage (VIH) | 0.7 x VCC to VCC + 0.3 V | |
| Output low voltage (VOL) | 0.2 V max | IOL = 100 uA |
| Output high voltage (VOH) | VCC - 0.2 V min | IOH = -100 uA |
| Endurance | 100,000 program/erase cycles | |
| Data retention | 20 years | |
