## Per-pin requirements

2-terminal part - the datasheet assigns no distinct requirement per terminal.

## Part-number structure

`RT` `0402` `B` `R` `D` `07` `44K8` `L`

| Field | Meaning | Code in this BOM |
|---|---|---|
| Series | RT, thin film | `RT` |
| Size | 0402 | `0402` |
| Tolerance | `B` = +/-0.1 % | `B` |
| Packaging | `R` = paper/PE taping reel | `R` |
| Temperature coefficient | `D` = 25 ppm/degC | `D` |
| Taping reel | `07` = 7 inch | `07` |
| Resistance | Letter marks the decimal point | `44K8`, `226K`, `10K` |
| Default code | Order only | `L` |
